# Econometrics-of-Financial-Markets
This repository serves as a working public record of my developing econometric skills and their application to financial markets. Current work focuses on autoregressive (AR) models, including simulation, autocorrelation structures, stationarity, and time-series analysis in R.

The repository will be updated progressively as I work through further financial econometric methods and applications.
